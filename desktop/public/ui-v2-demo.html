怎么点

右侧是说明；左侧是真实比例的菜单栏窗体原型。

  1. 顶栏切换 个人 / 团队，接线页与 footer 会变
  2. 五个主 Tab：概览 → 资源 → 诊断 → 接线 → 工作区
  3. 在「资源」里点列表项展开详情抽屉
  4. 概览待办可跳到诊断 / 资源
440×760 companion 延续现有蓝青玻璃壳 无真实 Tauri invoke

  1. 诊断不再是默认首页 → 概览 接管

  3. 效率嵌在概览条 + 资源效率分，不是账单大盘
